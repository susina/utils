Getting Started
===============

.. _StringUtils: classes/Susina-Utils-StringUtils.html
.. _SimpleInflector: classes/Susina-Utils-Inflector-SimpleInflector.html
.. _File: classes/Susina-Utils-File.html


Install the library via `composer <http://getcomposer.org>`_:

.. code:: bash
    composer require susina/utils


and you're ready to go!

The library provides tree classes: `StringUtils`_ , `File`_ and `SimpleInflector`_. 
The first one is a utility class for string manipulation, the second one is a utility class for file handling,
and the last one is a simple English pluralizer/singularizer class.
