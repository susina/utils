StringUtils.php : 32

Utility methods to manipulate strings, not included into the standard PHP functions list.

This class contains static methods to manipulate strings, such as converting to kebab-case, snake_case, StudlyCase, and camelCase. It also provides methods to ensure that a string starts or ends with a specific character.

All the static methods are intended to be used with the new PHP 8.5 pipe operator, allowing for a more functional programming style.

If you prefer the object-oriented fluent api approach, you can use the Text class, included into phootwork/lang package, or the UnicodeString class, from symfony/string package, instead.
